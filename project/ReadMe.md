PROJECT NAME: TRACK MY BUS
The Track My Bus is web application allows users to check real-time bus arrival timings at any Singapore bus stop. 
Design Process
The app helps commuters plan their journey efficiently by displaying upcoming bus arrivals, and passenger service details.
Main Page
 
Dropdown Menu
 
Features
User able to access following information through the app:
•	Real-Time Bus Arrival Timings
Shows next three bus arrivals for each service.
•	Search by Bus Stops Code
Search by bus stop code at nearby locations.
•	Contact
Allow user to contact for authority for other information and clarification
•	Passenger Volume service
Allow user to download bus service-related information.
